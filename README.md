# e-formation — Développement Web Fondamentaux

Ce dépôt contient les projets pédagogiques de la formation. Les exemples décrivent des situations **fictives** adaptées à Madagascar.

## Projets disponibles

- `projects/kanto-services/` — site HTML/CSS responsive avec navigation clavier et adaptation mobile, sans JavaScript ni backend.
- `projects/budget-tana/fondamentaux/` — premières fonctions et algorithmes JavaScript en console pour un budget fictif en MGA ; aucune interface de saisie, aucun stockage ni backend.

## Progression

HTML sémantique → styles CSS structurés → version responsive mobile-first, versionnement Git et publication statique documentée → JavaScript fondamental avec Budget Tana. Les états pédagogiques sont identifiés par leurs commits ; aucun tag n'est annoncé créé sans contrôle.

Voir `docs/publication-github-pages.md` pour activer et vérifier GitHub Pages. La présence d'un workflow ne prouve pas qu'un site est publié.

## Utilisation

Lire le README du projet concerné et ouvrir `index.html`. Les projets HTML/CSS et JavaScript console fonctionnent hors connexion après téléchargement du dossier complet.

## Prudence

Aucune donnée réelle, clé privée ou information personnelle n'est nécessaire. Les pages pédagogiques ne constituent ni une activité commerciale réelle ni une prestation professionnelle.
