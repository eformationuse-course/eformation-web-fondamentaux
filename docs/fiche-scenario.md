- **Lieu :** Antananarivo, Madagascar (pas d'adresse postale réelle).
- **Nature :** vitrine de démonstration HTML et CSS ; aucune offre commerciale.

- **Livrables fictifs :** modèle de lettre, guide de prise en main, plan de classement.

- **Données personnelles :** ne pas utiliser de vraies données dans les démonstrations.
- **Vérification :** navigation d'ancrage, alt, structure de titres, tableau de données, labels et champs, image locale.
